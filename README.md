# Language

Android-приложение для командной игры со словами и переводами на английском, немецком и французском языках. Поддерживает игроков, выбор наборов, таймер, результаты, собственный набор слов и темы оформления. Данные хранятся в Firebase Firestore.

## Запуск

1. Откройте эту папку в Android Studio.
2. Используйте JDK 17 и установите Android SDK 34. Минимальная версия Android — 8.1 (API 27).
3. Зарегистрируйте Android-приложение `com.language` в своём проекте Firebase, подключите Firestore и положите свою конфигурацию в `app/google-services.json`.
4. Настройте правила Firestore перед использованием: текущий код обращается к общему `languages/{language}/categories/{category}/words` и не выполняет аутентификацию.
5. Синхронизируйте Gradle и запустите приложение.

На Windows проверки запускаются командой:

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

В исходной среде проверки не запустились: отсутствует Java в PATH и не задан JAVA_HOME. Успешная сборка этой версии не подтверждена.
